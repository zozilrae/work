# 새 항목 추가 (New Item)

저장소에 새로운 작업 항목을 추가하는 워크플로우를 자동화한다.

## 워크플로우

**입력:** 항목 이름, 항목 설명, 자주 쓰는 명령(선택), 규약(선택)

**출력:**
- `<항목>` 폴더와 하위 파일 구조
- `<항목>/CLAUDE.md` 문서화
- `<항목>/README.md` 개요
- 루트 `CLAUDE.md` 및 `README.md` 업데이트

### 단계

1. **항목명 검증**
   - 소문자 + 하이픈 구분 (예: `battery-sim`, `cool-analysis`)
   - 특수문자 제거, 띄어쓰기는 하이픈으로
   - 기존 항목과 중복 체크

2. **폴더 구조 생성**
   ```bash
   cp -r _template <항목>
   ```
   결과:
   ```
   <항목>/
   ├── CLAUDE.md
   └── README.md
   ```

3. **`<항목>/CLAUDE.md` 채우기**
   - 자리표시(`<...>`) 모두 제거
   - 프롬프트:
     - 항목 제목: 무엇을 만드는 곳인가 (한국어)
     - 한 줄 설명: 가장 간단한 설명
     - 산출물: 어디에 쌓이는가
     - 자주 쓰는 명령: 저장소 루트에서 실행하는 형태
     - 의존성: 설치 필요한 것들
     - 규약: 파일/명명 규칙, 함정
   - 빈 섹션은 통째로 제거

4. **`<항목>/README.md` 채우기**
   - `# <항목 이름>`: 항목 제목
   - `<한 줄 설명>`
   - ## 산출물: 항목이 만드는 파일/산출물 표
     ```markdown
     | 항목 | 내용 | 갱신일 |
     |---|---|---|
     ```
   - ## 사용법: 기본 사용 명령

5. **루트 `CLAUDE.md` 업데이트**
   - "저장소 구조" 섹션의 항목 표에 새 행 추가:
     ```markdown
     | `<항목>/` | <한 줄 설명> |
     ```

6. **루트 `README.md` 업데이트**
   - 항목 표에 새 행 추가:
     ```markdown
     | [<항목>](<항목>/) | <한 줄 설명> | YYYY-MM-DD |
     ```
   - 시작일은 오늘 날짜

7. **검증**
   - 마크다운 문법 확인
   - 모든 자리표시(`<...>`) 제거됨
   - 루트 파일의 표 형식 정확
   - 새 항목의 CLAUDE.md/README.md 문법 검증

## 사용자 입력

### 필수 항목
- `item_name`: 항목 이름 (소문자, 하이픈 구분, 예: `battery-sim`)
- `title`: 항목 제목 (한국어, 예: "배터리 시뮬레이션")
- `description`: 한 줄 설명 (예: "배터리 모델 시뮬레이션 도구와 검증 스크립트")

### 선택 항목
- `commands`: 자주 쓰는 명령 (여러 개 가능, 예: `python3 battery-sim/main.py`)
- `dependencies`: 의존성 (예: `pip install numpy scipy matplotlib`)
- `conventions`: 규약 (마크다운 리스트, 예: "PEP 8 준수", "공백 4칸 들여쓰기")
- `subdirs`: 추가 하위폴더 (예: `scripts`, `data`, `output`)

## 규약 및 제약

- **항목명 형식:**
  - 소문자 + 하이픈 분리
  - 특수문자 미포함
  - 기존 항목(`_template` 제외)과 중복 불가
  - 예시: `reports`, `battery-sim`, `cool-analysis`

- **파일 구조:**
  - 최소: `CLAUDE.md`, `README.md`
  - `_template/` 복사로 시작, 자동 채우기로 완성

- **마크다운 규약:**
  - 경어 없음 (`~이다 / ~한다` 평서체)
  - 명령은 저장소 루트에서 실행하는 형태

- **커밋 메시지 형식:**
  ```
  chore(<항목>): 새 항목 추가
  
  - <항목명>/<CLAUDE.md> 기본 설정
  - <항목명>/README.md 개요
  - 루트 CLAUDE.md/README.md 항목 표 업데이트
  ```

## 실패 처리

- **항목명 중복:** 기존 폴더가 있으면 오류 후 중단
- **마크다운 문법 오류:** 자리표시 미제거 또는 형식 오류 시 사용자에게 알림
- **표 형식 오류:** 루트 파일 업데이트 시 마크다운 표 형식 검증

## 호출 시나리오

```
user: "새로운 항목을 만들고 싶은데, 시뮬레이션 도구를 위한 작업 공간이 필요해"
↓
skill: 항목명 결정 → _template 복사 → CLAUDE.md/README.md 채우기 → 
       루트 파일 업데이트 → 검증 → 커밋 제안
```

## 참고

- `_template/CLAUDE.md` 와 `_template/README.md` 는 자리표시 설명이 담겨 있음
- CLAUDE.md 의 "새 항목 추가" 섹션 참조
- 커밋은 한 항목 안에서 끝내야 함 (루트 파일 업데이트도 같은 커밋)
