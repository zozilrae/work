### TR-2026-001 — 펄스 히팅 기술 보고서 개요

저온 환경에서 리튬이온전지를 펄스/AC 전류로 내부 가열하는 자가발열 기술에 대한 실무 기술보고서.

- 저온 성능 저하 메커니즘 및 임피던스 주파수 특성
- 발열 모델링 (Bernardi 식, 임피던스 기반 발열량, 집중 열모델)
- 회로 토폴로지 5종 비교 (외부전원 / 팩분할 DC-DC / 모터·인버터 재구성 / 공진형 / 셀 내장형)
- 설계 파라미터(진폭·주파수·듀티비·SOC)와 리튬 석출 제약
- 문헌 성능 벤치마크 9건 정리
- 열화·안전성 분석 및 관련 규격
- 산업 동향 (CATL, BYD, 현대차그룹)
- 도입 절차, BMS 요구사항 체크리스트, 검증 시험계획

### TR-2026-002 — 자가 펄스 히팅 (LIB + 전고체) 보고서 개요

TR-2026-001의 범위를 전고체전지(ASSB)까지 확장해, 자가 펄스 히팅을 두 전지계 공통의 설계 프레임워크로 정리한 보고서.

**핵심 논지 — "동일한 원리, 상반된 동작점"**

| | LIB | ASSB |
|---|---|---|
| 가열 목적 | 저온 냉시동 (−30 → 0~25 °C) | 상시 운전온도 확보 (25 → 60~80 °C) |
| 최적 주파수 | 0.1 Hz ~ 1 kHz | 0.2 ~ 7 MHz |
| 구동 방식 | 전류원 (1~5C) | 전압원 (±1~2 V) |
| 발열원 | 전하이동 저항 R_ct | 고체전해질 옴저항 R_SE |
| 패러데이 전류 | 이용 (불가피) | 회피 (이중층 우회) |
| 주 제약 | 리튬 석출 | CCD·열응력·전위창 |

수록 내용

- 통합 물리 모델 — 전류/전압 구동 발열식, 주파수 축 위의 이중층 단락 기구
- ASSB 승온율·에너지 비용 차수 추정 (문헌 팩 시뮬레이션과 정합 확인)
- 제약 조건 분석 — 임계전류밀도(CCD), 계면 분해, 스택압·열팽창 불일치, 황화물 열안정성
- 펄스가 ASSB에서 CCD를 약 6배 확장한다는 문헌 결과와 그 함의
- 성능 벤치마크 및 **실측(0.5 K/min) vs 시뮬레이션(50 K/min) 격차에 대한 비판적 검토**
- 회로 구현 비교 — MHz 대역은 기존 트랙션 인버터 재활용 불가, GaN 전용 전력단 필요
- 전압 구동 시 자기 안정화가 성립하지 않을 가능성 (본 보고서 도출 해석)
- 산업 동향 (CATL, 삼성SDI, 도요타-이데미쓰, Blue Solutions) 및 특허 동향
- BMS 추가 요구사항 9항목, ASSB 검증 시험계획, 단기/중기/장기 권고
