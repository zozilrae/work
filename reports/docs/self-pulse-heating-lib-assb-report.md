# 리튬이온전지·전고체전지 공통 적용 자가 펄스 히팅(Self Pulse Heating) 기술 보고서

**문서번호** TR-2026-002
**작성일** 2026-09-17
**주제** 리튬이온전지(LIB) 및 전고체전지(ASSB)에 적용 가능한 펄스 전류·전압 기반 자가발열 기술
**분류** 실무 기술보고서 (엔지니어링 검토용)
**선행문서** TR-2026-001 「리튬이온전지 펄스 히팅 기술 조사·분석 보고서」(2026-09-14)

---

## 요약 (Executive Summary)

자가 펄스 히팅은 전지 외부에 히터를 두지 않고, 전지 자신의 내부 임피던스에 교번 전류·전압을 인가해 발생하는 손실열로 셀을 내부에서 직접 데우는 기술이다. 본 보고서는 이 기술을 **리튬이온전지(LIB)와 전고체전지(ASSB)에 공통으로 적용 가능한 하나의 설계 프레임워크**로 정리한다.

**핵심 결론은 "동일한 원리, 상반된 동작점"이다.** 두 전지계 모두 `Q = I²·Re{Z}` 라는 동일한 발열식을 따르지만, 최적 동작 주파수가 **5~6 자릿수 떨어져 있고**, 제약 조건과 구동 방식, 나아가 가열의 목적 자체가 다르다.

| 구분 | 리튬이온전지 (LIB) | 전고체전지 (ASSB) |
|---|---|---|
| 가열 목적 | 저온 **냉시동**(−30~0 °C → 0~25 °C) | 상온 포함 **상시 운전온도 확보**(25 °C → 60~80 °C) |
| 최적 주파수 | 0.1 Hz ~ 1 kHz (f_ct 근방) | **0.2 ~ 7 MHz** (이중층 단락 대역) |
| 구동 방식 | 전류원 (1~5C 진폭) | 전압원 (±1~2 V 구형파/정현파) |
| 발열 담당 임피던스 | 전하이동 저항 R_ct (저온에서 증폭) | 고체전해질 **벌크 옴저항 R_SE** |
| 승온율 상한 결정 요인 | **리튬 석출**(음극 전위 < 0 V vs Li/Li⁺) | **임계전류밀도(CCD)·계면 분해·스택압/열팽창** |
| 패러데이 전류 취급 | 발열의 원천 (불가피하게 이용) | **의도적으로 회피** (이중층으로 우회) |

LIB에서는 저온에서 커진 R_ct가 발열원이므로 **패러데이 반응을 이용해서 데운다**. 그 대가가 리튬 석출 위험이며, 설계는 "석출 임계선 아래에서 승온율 최대화"라는 제약 최적화가 된다(TR-2026-001 4.3절). 반면 ASSB에서는 MHz 대역에서 전기이중층이 커패시터처럼 동작해 전하이동 저항을 **단락**시키고, 그 결과 (1) 총 임피던스가 낮아져 같은 전압에서 전류·발열이 커지며 (2) 패러데이 반응 전류가 줄어 계면 분해와 리튬 침투가 억제된다. 즉 **"반응을 피하면서 데우는"** 정반대 전략이 성립한다.

**정량 수준** — LIB 펄스 히팅은 문헌 기준 승온율 3~7 °C/min, 승온 효율 약 30 %로 이미 양산 단계다(CATL 3세대 선싱, −30 °C에서 9분 내 98 % 충전). ASSB의 초고주파 자가발열(UHFSH)은 팩 시뮬레이션 기준 **50 K/min, 승온 에너지 3.4 %**가 보고되었으나, **실험 검증은 23.3 mAh 대칭셀에서 2분간 ΔT ≈ 0.85~1 °C 수준에 그친다.** 이 격차(측정값과 예측값 사이 약 2 자릿수)가 본 기술의 현재 성숙도를 규정하는 가장 중요한 사실이며, 본문 5장과 10장에서 별도로 다룬다.

**권고** — (1) LIB 라인은 TR-2026-001의 저주파 양방향 펄스(BPC) 설계를 그대로 추진하되, (2) ASSB 라인은 **MHz 대역 전력변환 하드웨어가 기존 인버터 재활용으로 불가능**하다는 점을 전제로 별도 GaN 기반 보조 전력단을 아키텍처 초기 단계에서 반영해야 한다. (3) 두 라인의 공통 자산은 회로가 아니라 **임피던스-열 연성 모델과 제약 관측기(observer)** 이므로, 이 계층을 화학 무관(chemistry-agnostic)하게 설계해 플랫폼화할 것을 권고한다.

## 1. 서론

### 1.1 배경 및 선행문서와의 관계

TR-2026-001은 리튬이온전지의 저온 펄스 히팅을 단독 주제로 다루었다. 본 보고서는 그 범위를 **전고체전지까지 확장**하되, LIB 관련 기초 내용(저온 임피던스 증가 메커니즘, 리튬 석출 제약, 회로 토폴로지 5종, 문헌 벤치마크 9건)은 중복 서술하지 않고 선행문서를 참조한다.

확장의 동기는 두 가지다.

1. **ASSB는 "저온 문제"가 아니라 "상온 문제"를 갖는다.** LIB는 상온에서 정상 동작하고 영하에서만 가열이 필요하지만, 산화물·폴리머계 ASSB는 **상온에서도 이온전도도와 계면 반응속도가 부족**하다. 폴리머(PEO)계는 상온 이온전도도가 10⁻⁶ S/cm 수준에 불과해 **60~80 °C 상시 가열이 필수**이며, 실제로 Blue Solutions의 LMP® 전지를 탑재한 BlueBus는 이 방식으로 상용 운행되고 있다. 즉 ASSB에서 가열은 냉시동 보조기능이 아니라 **운전 조건 그 자체**다.
2. **가열 수단으로서의 자가발열은 ASSB에서 더 유리한 조건을 갖는다.** ASSB는 Wh당 열질량이 LIB보다 15~20 % 작고, 산화물 고체전해질(LLZTO 2.2, LAGP 1.4 W/m·K)의 열전도도가 액체 전해질(0.2 W/m·K)보다 한 자릿수 높아 **승온이 빠르고 온도 구배가 작다**. 가열 필요성이 크고 가열 효율도 좋은 조합이다.

### 1.2 목적 및 범위

본 보고서는 자가 펄스 히팅을 LIB와 ASSB에 공통 적용 가능한 기술로 정식화하고, 두 전지계 사이의 물리적 차이가 설계 파라미터·회로·제어·검증에 어떤 차이를 만드는지 분석한다.

**범위에 포함**
- 전기적 자가발열(펄스 전류 / AC / 초고주파 전압 펄스)의 통합 물리 모델
- LIB ↔ ASSB 동작점 비교 (주파수, 진폭, 구동 방식, 제약 조건)
- ASSB 고유 제약 — 임계전류밀도(CCD), 계면 분해, 스택압·열팽창, 황화물 열안정성
- 회로 구현 난이도 비교 및 MHz 대역 전력단 요구사항
- 단계별 도입 지침 및 검증 계획

**범위에서 제외**
- 외부 히터(PTC·필름·액랭) 상세 설계 — 비교 목적으로만 언급
- 고체전해질 소재 개발, 셀 제조공정(소결·가압·적층)
- 나트륨이온 등 타 화학계

### 1.3 용어 정의

| 용어 | 정의 |
|---|---|
| 자가발열 (Self-Heating) | 외부 열원 없이 전지 내부 임피던스의 손실로 전지 자신을 가열하는 방식 |
| BPC (Bidirectional Pulse Current) | 충·방전 펄스를 교번 인가하는 양방향 펄스. 순 전하이동이 작음 |
| UHFSH (Ultra-High-Frequency Self-Heating) | 10⁵ Hz 이상 교번 전압으로 ASSB를 가열하는 방식 (Zhang et al., *Joule*, 2025) |
| f_ct | 전하이동 반응의 특성 주파수. LIB −20 °C에서 0.1~10 Hz 수준 |
| 이중층 단락 (Double-Layer Shunting) | 고주파에서 전기이중층 커패시턴스의 리액턴스가 작아져 전하이동 저항을 우회시키는 현상 |
| CCD (Critical Current Density) | 고체전해질에서 리튬 필라멘트(덴드라이트)가 생성되지 않는 최대 전류밀도 |
| ASR (Area-Specific Resistance) | 면적비저항 [Ω·cm²]. 셀 크기와 무관하게 비교하기 위한 지표 |
| 반응전류 / 이중층전류 | 총 전류의 분해. i = i_rxn(패러데이) + i_inf(이중층 변위전류) |
| 스택압 (Stack Pressure) | ASSB 계면 접촉 유지를 위해 셀 적층 방향에 가하는 외부 압력 (통상 수백 kPa ~ 수 MPa) |

## 2. 두 전지계의 문제 정의 비교

### 2.1 무엇이 성능을 제한하는가

**LIB (저온)** — 상세는 TR-2026-001 2장 참조. 요지는 전해질 이온전도도 저하, 음극 전하이동 저항 R_ct 급증, 고상 확산 저하이며, −20 °C에서 내부저항이 상온 대비 5~10배 증가한다. 결정적 제약은 저온 충전 시 **리튬 석출**이다.

**ASSB (상온 포함 전 영역)** — 제한 요인의 구조가 다르다.

1. **벌크 이온전도도** — 황화물계는 상온 10⁻³~10⁻² S/cm로 액체 전해질에 필적하나, 산화물계·폴리머계는 이보다 1~4 자릿수 낮다. 특히 PEO계는 10⁻⁶ S/cm 수준으로 **상온 동작이 사실상 불가능**하다.
2. **계면 저항이 지배적** — ASSB의 율속 단계는 대개 벌크가 아니라 **복합 양극 내 활물질/고체전해질 계면**이다. 계면 반응층(interphase)의 활성화 에너지는 코팅 유무에 따라 크게 달라져, 예컨대 Ni90 양극/황화물 계면에 Li₂ZrO₃ 코팅을 삽입하면 활성화 에너지가 60.19 → 41.39 kJ/mol로 감소한다는 보고가 있다. 활성화 에너지가 높다는 것은 곧 **온도 민감도가 크다**는 뜻이며, 이는 가열의 효과가 크다는 의미이기도 하다.
3. **고상-고상 물리적 접촉** — 액체 전해질처럼 젖어들지 않으므로 접촉 면적이 스택압과 부피변화에 좌우된다. 접촉 손실은 국부 전류집중으로 이어진다.

### 2.2 가열 목표 온도의 비대칭성

이 차이는 시스템 설계에 직접적인 결과를 낳는다.

```
LIB                                  ASSB
 −30 °C ────► 0~25 °C                 25 °C ────► 60~80 °C
 │                                    │
 ├─ 겨울철·충전 전에만 (간헐)          ├─ 상시 또는 빈번 (연중)
 ├─ 도달 후 가열 종료                  ├─ 도달 후 **유지 가열** 필요
 └─ 승온 에너지 = 1회성 비용           └─ 승온 + 보온 에너지 = 지속 비용
```

- **LIB의 가열은 이벤트**다. 연간 수십~수백 회, 회당 3~10분. 총 에너지 비용은 작다.
- **ASSB의 가열은 상태**다. 승온 후 목표 온도를 유지해야 하므로, 방열 손실을 보상하는 **연속 보온 전력**이 필요하다. 따라서 ASSB에서는 **단열 설계가 가열 회로 설계만큼 중요**해진다. 문헌의 팩 시뮬레이션이 열전달계수 h = 10 W/m²K 조건에서 1시간 운전 기준 3.4 %라는 낮은 에너지 비용을 제시할 수 있는 이유도 대형 팩의 낮은 표면적/부피비에 기인한다.

### 2.3 안전 여유의 비대칭성

| 항목 | LIB | ASSB |
|---|---|---|
| 가열 상한 | 전해액 분해·SEI 열화 개시 ~60 °C, 열폭주 개시 130~200 °C | 목표 온도 자체가 60~80 °C로 **정상 동작점이 LIB의 경고 영역** |
| 가열 중 주요 위험 | 리튬 석출, 국부 과열 | 계면 분해, 리튬 침투, **접촉 손실**, 황화물 가스 발생 |
| 열폭주 개시 | 전해액 기화·분리막 수축 | 황화물계는 **160 °C 이하**에서 전극/전해질 계면 발열 반응 개시 보고. 200 °C 부근 NCM 방출 산소에 의한 황화물 산화, 300 °C 부근 고상 반응 단계 |
| 가스 위험 | 가연성 유기가스 | **H₂S, SO₂ 등 독성·부식성 가스** |

**중요한 오해 정정** — "전고체는 안전하므로 가열해도 된다"는 통념은 성립하지 않는다. 황화물계 ASSB의 열폭주는 오히려 예상보다 낮은 온도에서 개시될 수 있다는 것이 최근 연구의 공통된 지적이며, 양극/티오인산염 전해질 간 화학적 계면 불안정성이 주된 트리거로 지목된다. 목표 온도(60~80 °C)와 계면 발열 개시 온도(~160 °C) 사이의 여유가 LIB만큼 넓지 않으므로, **ASSB의 가열 제어는 오히려 더 엄격한 온도 상한 관리와 국부 핫스팟 억제를 요구한다.**

## 3. 통합 물리 모델 — 하나의 식, 두 개의 동작점

### 3.1 공통 발열식

두 전지계 모두 주기 정상상태에서 동일한 발열식을 따른다. 차이는 식이 아니라 **어느 주파수의 Re{Z}를 쓰느냐**에 있다.

**전류 구동(LIB 관례)**

```
Q_gen = Σ_n  I_n,rms² · Re{ Z(n·f₀, T, SOC) }
```

**전압 구동(ASSB / UHFSH 관례)**

```
                    Re{Z(f,T)}
Q_gen = V_cell,rms² · ──────────
                     |Z(f,T)|²
```

두 식은 등가이며(`I = V/|Z|`), 실제 시스템이 전류원으로 구동되는지 전압원으로 구동되는지에 따라 편한 형태를 쓴다. **이 구동 방식의 차이가 본 보고서에서 다루는 가장 실무적인 분기점이다** (3.4절).

열 모델은 공통이다.

```
m · c_p · dT/dt = Q_gen(T) − h · A · (T − T_amb)
```

### 3.2 주파수 축 위의 통합 관점

전지의 계면은 **패러데이 반응 경로(R_ct)와 전기이중층 커패시턴스(C_dl)의 병렬 조합**으로 모델링된다. 총 전류는 두 경로로 분배된다.

```
i_total = i_rxn (패러데이, 화학변화 유발)  +  i_inf (이중층 변위전류, 화학변화 없음)
```

주파수가 올라가면 C_dl의 리액턴스 `1/(2πfC_dl)`가 작아져 전류가 점점 이중층 쪽으로 흐른다. 즉

- **저주파** — i ≈ i_rxn. 발열은 크지만 **모든 전류가 화학반응을 일으킨다.**
- **고주파** — i ≈ i_inf. 화학반응은 거의 없고, 전류는 계면을 커패시터로 통과해 **벌크 옴저항에서만 열이 난다.**

이 하나의 그림에서 LIB와 ASSB의 전략이 갈린다.

```
   Re{Z}
     ↑
     │ ╲                                      LIB 동작점
     │  ╲___  R_ct 지배 영역                  (Re{Z} 큰 곳을 노림)
     │      ╲___                        ↓
     │          ╲______              ┌──────┐
     │                 ╲____________ │ f_ct │ ──────────────┐
     │                               └──────┘                │
     │                                        R_ohm 수렴     │
     │                                  ───────────────────  │
     │                                   (LIB: 작다 → 발열↓) │
     │                                   (ASSB: R_SE 가 크다 │
     │                                    → 발열 충분)       │
     └──────┬──────────┬──────────┬──────────┬──────────┬───→ f
          0.1 Hz      10 Hz      1 kHz     100 kHz     10 MHz
          └── LIB 가열 대역 ───┘            └─ ASSB(UHFSH) 대역 ─┘
```

**왜 LIB는 고주파로 갈 수 없는가** — LIB에서 R_ct를 단락시키면 남는 것은 매우 작은 옴저항뿐이다(예: CATL 3세대 선싱 셀의 내부저항은 0.25 mΩ로 업계 평균 대비 50 % 낮다고 발표되었다). 발열을 확보하려면 비현실적으로 큰 전류가 필요해진다. 따라서 LIB는 **R_ct가 큰 저주파 대역을 일부러 사용**하고, 그 대가로 리튬 석출 위험을 제어로 관리한다.

**왜 ASSB는 고주파로 가야 하는가** — ASSB에서 이중층으로 R_ct와 계면 반응층 저항을 단락시켜도, **고체전해질 자체의 벌크 옴저항이 충분히 크게 남는다.** 두께 25 µm, 이온전도도 10⁻⁴ S/cm 기준 면적비저항은

```
ASR_SE = L / σ = 25×10⁻⁶ m / 10⁻² S·m⁻¹ = 2.5×10⁻³ Ω·m² = 25 Ω·cm²
```

즉 고체전해질이 그 자체로 훌륭한 발열체다. 동시에 패러데이 전류가 줄어 계면이 보호된다. **ASSB에서 초고주파는 "발열을 포기하는 대가"가 아니라 "발열과 안전을 동시에 얻는 선택"이다.**

### 3.3 주파수 상한 — 인덕턴스

주파수를 무한히 올릴 수는 없다. 문헌은 다음의 비단조(non-monotonic) 거동을 보고한다.

- **저주파** — 계면·전하이동 임피던스 지배, 발열 낮음
- **중~고주파** — 이중층이 R_ct를 단락, |Z| 감소 → **발열 최대**
- **초고주파** — 적층 구조의 **인덕턴스가 지배**, |Z| 재상승 → 발열 감소

따라서 최적 주파수가 존재한다. 보고된 값은 셀 구조에 강하게 의존한다.

| 셀 구조 | 최적/포화 주파수 | 근거 |
|---|---|---|
| 단층 대칭셀 (Li\|LAGP\|Li, 23.3 mAh) | 2 MHz 이상에서 ΔT 포화 (0.5~7 MHz 스윕) | 인덕턴스 무시 가능 |
| 다층 파우치/팩 (LCO\|LAGP\|Li, 19 Wh~62 kWh) | **0.2 MHz** | 적층 인덕턴스로 최적점이 한 자릿수 하향 |

**설계 함의** — **셀이 커질수록 최적 주파수는 내려간다.** 단층 코인셀 실험에서 얻은 최적 주파수를 팩에 그대로 적용하면 안 되며, 최적 주파수는 대상 셀의 실측 EIS(인덕턴스 영역 포함, 최소 MHz까지)로 재도출해야 한다. 참고 문헌의 EIS 측정 범위는 0.1 Hz ~ 7 MHz, 디케이드당 20점이다.

### 3.4 구동 방식 — 전류원 vs 전압원

실무적으로 가장 중요한 차이다.

| | LIB 펄스 히팅 | ASSB UHFSH |
|---|---|---|
| 제어 변수 | **전류** (1~5C) | **전압** (±1~2 V 구형파/정현파) |
| 제한 조건 | 음극 전위 ≥ 0 V vs Li/Li⁺ (석출) | 셀 전압 스윙 < 전기화학적 안정 전위창 |
| 안정 전위창 예 | 셀 전압 2.5~4.2 V (LFP 2.0~3.65 V) | LCO/NMC\|Li 기준 4.35~2.35 V → **총 스윙 2 V 이내** |
| 왜 그 방식인가 | 석출은 전류(과전압)로 결정되므로 전류를 직접 제한해야 함 | |Z|가 주파수·온도에 따라 크게 변해 전류 제어가 불안정. 전압 리미트가 물리적 안전 경계 |

ASSB 문헌에서 인가 전압은 대칭셀 실험에서 ±2 V 정현파(LAGP 최대 안정 전위의 약 절반), 팩 시뮬레이션에서 ±1 V 구형파가 사용되었다. **전압 스윙 총폭이 해당 화학계의 안정 전위창을 넘지 않아야 한다**는 것이 ASSB 측의 1차 설계 제약이다.

### 3.5 설계 예제 — ASSB 승온율 차수 추정

TR-2026-001 4.2절(LIB 50 Ah LFP 예제)에 대응하는 ASSB 예제를 제시한다. **가정값 기반 차수 추정이며, 실제 설계는 실측 EIS로 재수행해야 한다.**

전제 (LCO\|LAGP\|Li 적층 파우치, 고주파 극한에서 |Z| → R_SE)

| 항목 | 값 | 근거 |
|---|---|---|
| 고체전해질 두께 L | 25 µm | LIB 분리막과 동등 수준 (문헌 기준값) |
| 이온전도도 σ (25 °C) | 10⁻⁴ S/cm | 문헌 팩 시뮬레이션 가정값 |
| 면적비저항 ASR_SE | 25 Ω·cm² | L/σ |
| 인가 전압 (층당) | ±1 V (rms ≈ 1 V, 구형파) | 안정 전위창 이내 |
| 단위 적층 두께 | 150 µm | 양극 60 + SE 25 + Li 20 + 집전체 등 |
| 적층 체적 열용량 ρ·c_p | 2.24×10⁶ J/(m³·K) | ρ ≈ 2,800 kg/m³, c_p ≈ 800 J/(kg·K) |

**면적 발열 밀도**

```
q″ = V² / ASR_SE = (1 V)² / 2.5×10⁻³ Ω·m² = 400 W/m² = 0.04 W/cm²
```

**체적 발열 밀도 및 단열 승온율**

```
q‴ = q″ / 150×10⁻⁶ m = 2.67×10⁶ W/m³
dT/dt = q‴ / (ρ·c_p) = 2.67×10⁶ / 2.24×10⁶ ≈ 1.19 K/s ≈ 71 K/min
```

방열과 비이상성을 감안하면 문헌의 팩 시뮬레이션 값(**50 K/min**)과 같은 차수로 정합한다.

**승온 에너지 비용**

ΔT = 40 K 승온에 필요한 체적 열에너지는

```
E_th = ρ·c_p·ΔT = 2.24×10⁶ × 40 = 8.96×10⁷ J/m³ = 89.6 MJ/m³
```

ASSB 체적 에너지밀도를 700~800 Wh/L (2.52~2.88×10⁹ J/m³)로 두면

```
E_th / E_cell = 89.6×10⁶ / (2.52~2.88)×10⁹ = 3.1 ~ 3.6 %
```

문헌의 **3.4 %** (104 kWh 팩, ΔT = 40 K, 1시간 운전, h = 10 W/m²K)와 정합한다.

**LIB 예제와의 비교**

| | LIB (TR-2026-001 4.2절) | ASSB (본 절) |
|---|---|---|
| 승온폭 | 20 K (−20 → 0 °C) | 40 K (25 → 65 °C) |
| 순수 열에너지 / 셀 에너지 | 5.4 % | **3.1~3.6 %** |
| 승온율 (단열 근사) | 7.8 °C/min | 71 °C/min |

ASSB는 승온폭이 2배임에도 **에너지 비용이 오히려 낮다.** 이유는 (1) 체적 에너지밀도가 높아 분모가 크고, (2) Wh당 열질량이 LIB 대비 15~20 % 작기 때문이다. 다만 위 값은 **순수 열에너지 기준**이며, 전력변환 효율과 보온 전력(ASSB는 지속 소모)을 반영하면 실제 SOC 비용은 이보다 커진다. LIB 측 실측 승온 효율이 약 30 %임을 감안하면, ASSB 역시 **시스템 효율이 최종 비용을 좌우**한다는 결론은 동일하다.

## 4. 제약 조건 분석 — 무엇이 승온율의 상한을 정하는가

가열 설계의 본질은 "얼마나 빨리 데울 수 있는가"가 아니라 **"무엇이 먼저 파괴되는가"**를 찾는 일이다.

### 4.1 LIB — 리튬 석출 (요약)

상세는 TR-2026-001 4.4절 및 7장 참조. 요지만 정리한다.

- 충전 반주기 중 음극 전위 η_a가 Li/Li⁺ 기준 0 V 이하로 내려가면 금속 리튬이 석출된다.
- **고SOC일수록 위험이 급증**한다. 음극이 이미 리튬으로 포화되어 U_a가 낮기 때문이다.
- 대응: SOC 의존적 진폭 제한 테이블, 양방향 펄스로 분극 상쇄, 방전 진폭을 충전보다 크게 설정.

### 4.2 ASSB — 임계전류밀도(CCD)와 리튬 침투

고체전해질에서의 파괴 모드는 액체계의 "석출"과 다르다. 금속 리튬이 **고체전해질의 결정립계·기공·미세결함을 따라 침투해 필라멘트(덴드라이트)를 형성**하고, 결국 관통 단락에 이른다. 이를 규정하는 지표가 **임계전류밀도(CCD)** — 리튬 필라멘트가 생기지 않는 최대 전류밀도다.

**CCD는 재현성이 낮은 지표다.** 동일 고체전해질이라도 스택압, 온도, 계면 처리, 측정 프로토콜에 따라 값이 크게 흩어지며, 표준화된 측정 절차의 필요성이 반복 지적되고 있다. 따라서 **문헌 CCD 값을 설계 한계로 직접 차용해서는 안 되며, 자사 셀·자사 스택압 조건에서 재측정해야 한다.**

### 4.3 핵심 발견 — 펄스는 ASSB에서 제약이 아니라 완화 수단이다

LIB에서 펄스는 "석출을 유발할 수 있는 위험 요인"이다. ASSB에서는 **정반대의 결과가 보고된다.**

Reisecker 등(*Nature Communications*, 2023)은 MHz 대역 펄스 전류(펄스:휴지 = 1:1, µs 영역)를 인가했을 때 다결정 고체전해질에서 다음을 관측했다.

| 항목 | DC | MHz 펄스 |
|---|---|---|
| 임계전류밀도 (다결정) | ~1 mA/cm² 수준 | **6.6 ± 0.1 mA/cm²** (약 6배) |
| 덴드라이트 성장률 증가 기울기 | 13.7 µm/(s·mA/cm²) | **1.1 µm/(s·mA/cm²)** |
| 단결정 시료 | — | 개선 효과 미미 |

**메커니즘** — 덴드라이트에 의한 전해질 파괴는 **리튬 이온 활동도가 결함 선단에서 임계값까지 축적되는 데 일정 시간이 필요**하다. 펄스 휴지 구간에서 이온이 확산으로 흩어지면 그 축적이 일어나지 못한다. 따라서 **펄스 지속시간을 임계 축적 시간보다 짧게 유지하면 안정 영역이 확장된다.**

이 결과는 본 보고서의 관점에서 두 가지 의미를 갖는다.

1. **UHFSH의 안전성 논거를 독립적으로 뒷받침한다.** MHz 대역에서 (a) 이중층 단락으로 패러데이 전류 자체가 줄고, (b) 남은 패러데이 전류도 펄스 형태이므로 CCD 여유가 확대된다. 두 효과가 같은 방향으로 작용한다.
2. **효과는 미세구조 의존적이다.** 다결정에서만 유효하고 단결정에서는 미미했다는 점은, 펄스 효과가 **결정립계 경로를 통한 침투를 지연시키는 기구**임을 시사한다. 자사 고체전해질의 미세구조(소결 밀도, 결정립 크기, 기공률)에 따라 효과가 달라질 수 있다.

### 4.4 ASSB 고유 제약 — 기계적 계면

LIB에는 존재하지 않는 제약이다. **가열 자체가 기계적 손상을 유발할 수 있다.**

- **스택압의 양날** — 스택압은 계면 접촉을 개선해 임피던스를 낮추고 안정적 사이클링을 가능하게 하지만, 과도하면 **파괴, 계면 박리, 리튬 침투를 촉발**한다. 즉 최적 구간이 존재한다.
- **열팽창 계수 불일치** — 고체전해질과 전극은 모두 강직(rigid)하며 열팽창 계수가 서로 다르다. 온도가 변하면 계면에 기계적 응력이 발생해 **미세균열, 계면 박리, 접촉 손실**로 이어질 수 있다.
- **결과의 연쇄** — 접촉 손실 → 국부 저항 증가 → 전류 분포 불균일 → 국부 전류밀도가 CCD 초과 → 리튬 침투 가속. 또한 새로 노출된 반응면에서 화학적 부반응이 진행된다.

**설계 함의** — ASSB의 자가발열은 **승온율뿐 아니라 온도 변화율(dT/dt)에 의한 열응력도 제약 대상**이다. LIB에서 dT/dt는 승온 속도 지표에 불과하지만, ASSB에서는 그 자체가 열화 인자다. 50 K/min급 승온이 계면 건전성에 미치는 영향은 **현재 공개 문헌에서 검증되지 않은 영역**이며, 본 기술의 최대 미확인 리스크다(10장).

### 4.5 제약 조건 종합

| 제약 | LIB | ASSB | 관측/제어 가능성 |
|---|---|---|---|
| 리튬 석출 / 침투 | 음극 전위 < 0 V | CCD 초과 | LIB: 전위 관측기·dEIS(신뢰도 논쟁 있음) / ASSB: 직접 관측 수단 부재 |
| 계면 열화 | SEI 성장 | interphase 성장·분해 | 둘 다 사후 EIS로만 |
| 기계적 손상 | 해당 없음 (액체가 접촉 보상) | **열팽창 불일치·박리** | 스택압 모니터링, 팽창 센서 |
| 온도 상한 | ~60 °C | 목표가 60~80 °C, 계면 발열 개시 ~160 °C | 온도센서 (국부 핫스팟 관측이 관건) |
| 가스 발생 | 가연성 유기가스 | **H₂S·SO₂ 독성 가스** | 압력·가스 센서 |
| 전압 제약 | 셀 전압 리미트 | 안정 전위창(총 스윙) | 직접 측정 가능 |

**LIB와 ASSB의 가장 큰 실무적 차이는 "제약을 관측할 수 있는가"에 있다.** LIB는 리튬 석출을 음극 전위라는 물리량으로 환원해 관측기를 설계할 수 있으나, ASSB의 CCD 초과와 계면 박리는 **실시간 관측 수단이 사실상 없다.** 따라서 ASSB 가열 제어는 당분간 **관측 기반 폐루프가 아니라, 보수적 마진을 둔 개루프 스케줄(온도·SOC·전압 룩업)로 설계**할 수밖에 없다.

## 5. 성능 벤치마크

### 5.1 LIB (요약)

TR-2026-001 6장에 9건이 정리되어 있다. 요지는 **승온율 3~7 °C/min, 승온 효율 약 30 %**가 현실적 설계 목표이며, 17 °C/min급 보고값은 소형·고단열·극한 조건의 값이다. 산업 적용은 양산 단계에 진입했다(8장).

### 5.2 ASSB

**보고 건수가 매우 적다.** 자가 펄스 히팅을 ASSB에 적용한 공개 문헌은 사실상 아래 1건이 중심이며, 나머지는 외부 히터 또는 소재적 접근이다.

| # | 방식 | 대상 | 조건 | 결과 | 검증 수준 |
|---|---|---|---|---|---|

### 5.3 벤치마크 해석 — 반드시 유의할 점

**1. 실측과 예측 사이에 약 2 자릿수의 격차가 있다.**

```
실험 검증됨  ────────►  ΔT ≈ 1 °C / 2 min  =  0.5 K/min   (23.3 mAh 대칭셀)
시뮬레이션   ────────►  50 K/min                          (62 kWh 팩)
                         ↑
                   100배 차이
```

이 격차 자체가 오류인 것은 아니다. 소형 단층 셀은 표면적/부피비가 커서 발생 열의 대부분을 잃는 반면, 팩은 낮은 표면적/부피비가 단열체로 작용한다(문헌도 2층 셀이 단층보다 승온이 빨랐음을 보이며 이 논리를 뒷받침한다). 그러나 **50 K/min은 어디까지나 모델 외삽이며, 실측된 적이 없다.** 팩 레벨 실증 없이 이 값을 사양으로 인용해서는 안 된다.

**2. 실험은 대칭셀(Li|LAGP|Li)이지 풀셀이 아니다.**

대칭셀에는 양극이 없다. ASSB 임피던스의 지배 요인이 **복합 양극 내 계면**임을 고려하면, 대칭셀 결과는 고체전해질 벌크 발열 기구를 입증할 뿐 **풀셀의 발열 분포·계면 응답을 대표하지 않는다.** 실제 셀에서는 양극 복합체 내부에 발열이 집중될 가능성이 있으며, 이는 국부 핫스팟 관점에서 검증이 필요하다.

**3. 사이클 열화 데이터가 없다.**

LIB 펄스 히팅조차 30~90 사이클 수준의 열화 검증에 머물러 있다는 것이 TR-2026-001의 지적이었다. ASSB UHFSH는 **반복 가열에 따른 열화 데이터가 공개 문헌에 사실상 존재하지 않는다.** 4.4절의 열팽창·박리 리스크를 고려하면 이는 심각한 공백이다.

**4. 시뮬레이션의 열전달계수는 피팅 파라미터다.**

문헌 모델에서 유일한 피팅 파라미터는 파우치-외기 간 열전달계수 h이며, 단층 25, 2층 20 W/m²K로 추정되었다. 팩 예측에는 h = 10~25 W/m²K가 사용되었다. **h는 곧 단열 설계이며, 실제 팩의 h가 가정보다 크면 승온율과 에너지 비용이 모두 악화된다.**

## 6. 회로 구현 — 난이도의 비대칭

### 6.1 LIB 측 (요약)

TR-2026-001 5장의 5종 토폴로지(외부전원 / 팩분할 DC-DC / 모터·인버터 재구성 / 공진형 / 셀 내장형)가 그대로 적용된다. 핵심 이점은 **기존 구동계 부품의 재활용**이다. BYD가 모터·인버터를 이용한 고주파 펄스 승온을 채택한 것이 대표 예다.

### 6.2 ASSB 측 — 기존 자산을 쓸 수 없다

**MHz 대역은 차량 전력변환의 기존 영역 밖이다.** 이것이 ASSB 자가발열 도입의 최대 실무 장벽이다.

| 항목 | LIB 펄스 히팅 | ASSB UHFSH |
|---|---|---|
| 스위칭 주파수 | 0.1 Hz ~ 1 kHz | **0.2 ~ 7 MHz** |
| 기존 인버터 재활용 | 가능 (10~20 kHz 스위칭으로 충분) | **불가능** — 트랙션 인버터 대역을 2~3 자릿수 초과 |
| 반도체 | Si IGBT / SiC MOSFET | **GaN HEMT 급 필수** |
| 자기부품 | 기존 모터 권선 활용 가능 | 전용 설계, 코어 손실 지배 |
| 배선 기생성분 | 무시 가능 | **인덕턴스가 최적 주파수를 결정** (3.3절) — 버스바·하네스 레이아웃이 성능 파라미터가 됨 |
| EMI | 관리 가능 | **주요 설계 제약** — MHz 대역은 방송·통신 대역과 중첩, CISPR 25 대응 필수 |
| 추가 부품 | 최소 | 전용 고주파 전력단 + 필터 + 차폐 |

**설계 함의 — 아키텍처 초기 단계의 결정 사항이다.** LIB 펄스 히팅은 기존 하드웨어에 제어 소프트웨어를 얹어 후반부에 추가할 여지가 있으나, ASSB UHFSH는 **전용 고주파 전력단·배선 레이아웃·차폐 설계가 필요**하므로 팩 아키텍처 확정 전에 반영되어야 한다. 사후 추가는 사실상 재설계를 의미한다.

### 6.3 구현 옵션 비교 (ASSB)

| 방식 | 설명 | 장점 | 단점 |
|---|---|---|---|
| **전용 GaN 고주파 전력단** | 팩에 MHz급 전압 소스 탑재 | 문헌 조건 직접 구현 | 비용·중량·EMI |
| **모듈 분할 상호 가열** | 모듈 간 고주파 에너지 교환 | 외부 전원 불필요 | 제어 복잡, 모듈 간 배선 인덕턴스 |
| **저주파 자가발열 + 외부 히터 하이브리드** | 승온은 외부 히터, 유지는 자가발열 | 하드웨어 부담 완화 | 승온율 열위, 히터 중량 |
| **외부 필름 히터 단독** | 폴리이미드 필름 등 | 성숙 기술, 65~75 °C 유지 실증 | 열전달 경로 존재, 승온 느림, 온도 구배 |

**현 시점 권고** — ASSB 양산 일정(삼성SDI 2027년 양산 목표, 도요타-이데미쓰 고체전해질 파일럿 플랜트 2027년 말 완공 목표)을 고려하면, **1세대는 외부 필름 히터 또는 하이브리드가 현실적**이다. UHFSH는 2세대 이후 옵션으로 두고, 지금은 **셀·모듈 레벨 MHz EIS 데이터 확보와 소형 실증**에 자원을 투입하는 것이 합리적이다.

## 7. 열화 및 안전성

### 7.1 열화 경로 비교

| 경로 | LIB | ASSB | 가열에 의한 촉진 여부 |
|---|---|---|---|
| 리튬 석출/침투 | 저주파 충전 펄스 시 | CCD 초과 시 | LIB: **촉진**, ASSB: 고주파에서 **억제**(4.3절) |
| 계면층 성장 | SEI 성장 가속 | interphase 성장·전해질 자기분해 | 양쪽 모두 **온도에 따라 가속** |
| 기계적 손상 | 해당 없음 | 열팽창 불일치 → 박리·미세균열 | ASSB **고유 리스크**, 반복 가열 시 누적 |
| 가스 발생 | 고온에서 전해액 분해 | 황화물계 H₂S·SO₂ | ASSB는 **독성** 관점 추가 관리 |
| 온도 불균일 | 셀 간 편차 → SOC 불균일 | 국부 핫스팟 → 국부 CCD 초과 | 양쪽 모두 팩 레벨 과제 |

### 7.2 상반된 온도 의존성 — 설계상의 딜레마

**가열은 성능을 올리는 동시에 열화를 가속한다.** 이 양면성은 두 전지계에서 다르게 나타난다.

- **LIB** — 가열의 목표 온도(0~25 °C)가 열화 가속 영역(>45 °C)에서 충분히 멀다. 즉 **성능과 수명이 같은 방향**이다.
- **ASSB** — 목표 온도(60~80 °C)가 이미 아레니우스적으로 부반응이 빨라지는 영역이다. **성능과 수명이 반대 방향**이며, 운전 온도 선정 자체가 트레이드오프가 된다.

따라서 ASSB에서는 "필요한 만큼만, 필요한 시간만 데운다"는 제어가 LIB보다 훨씬 중요하다. 구체적으로는 요구 출력에 따라 목표 온도를 동적으로 낮추는 **부하 적응형 온도 스케줄**이 유효한 전략이다. 문헌도 UHFSH의 장점으로 "스마트 열관리 시스템에서 최적 운전온도를 즉각 조정할 수 있다"는 점을 들고 있다.

### 7.3 자기 안정화 특성의 차이

LIB 펄스 히팅은 온도가 오르면 Re{Z}가 감소해 발열이 자연히 줄어드는 **자기 안정화(self-limiting)** 특성을 가진다(TR-2026-001 4.1.3절). 안전 관점에서 유리한 성질이다.

ASSB에서도 온도 상승에 따라 이온전도도가 올라가 R_SE가 감소하므로 정성적으로 같은 방향이다. 다만 **전압 구동 방식에서는 `Q = V²·Re{Z}/|Z|²` 이므로 저항 감소가 곧바로 발열 감소를 뜻하지 않는다.** |Z|가 R_SE에 지배될 때 Q ≈ V²/R_SE가 되어, **저항이 줄면 오히려 발열이 늘어난다.** 즉 **전압 구동 ASSB 가열은 자기 안정화가 아니라 정(+)의 피드백을 가질 수 있다.**

> **이는 본 보고서가 문헌 데이터로부터 도출한 해석이며, 원 논문이 명시적으로 다룬 논점은 아니다.** 다만 전압 구동의 수식 구조상 필연적으로 검토되어야 할 사항이므로, 설계 시 **온도 기반 전압 디레이팅 또는 전류 리미트를 명시적으로 두어 열폭주 경로를 차단**할 것을 강하게 권고한다. 실제 하드웨어 설계 전 반드시 자사 셀 모델로 부호를 확인해야 한다.

### 7.4 관련 규격

- **LIB** — IEC 62660 시리즈, UN 38.3, ISO 6469 등 (TR-2026-001 7.3절)
- **ASSB** — **전용 안전 규격이 아직 정립 단계**다. 기존 LIB 규격의 열폭주 시험 조건(전해액 기화 전제)이 고체계에 그대로 적용되지 않으며, 셀 레벨 열안전성 평가 방법론 자체가 연구 주제로 남아 있다. 황화물계의 H₂S 발생은 기존 규격이 다루지 않는 항목이다.
- **EMI** — ASSB UHFSH 도입 시 **CISPR 25 / UN ECE R10** 대응이 신규 부담으로 추가된다 (6.2절).

## 9. 실무 도입 지침

### 9.1 공통 설계 절차

두 전지계에 공통으로 적용되는 6단계다. **3~4단계의 내용만 화학계에 따라 달라진다.**

```
1. 셀 특성화      → 광대역 EIS 측정 (온도 × SOC 그리드)
2. 발열 모델 구축  → Q(f, T, SOC) 맵 작성, 열모델과 연성
3. 제약 조건 정의  → LIB: 석출 임계선 / ASSB: CCD·전위창·열응력
4. 동작점 최적화   → 제약 하 승온율 최대화
5. 팩 스케일 검증  → 온도·SOC 불균일, 국부 핫스팟
6. 가속 열화 검증  → 반복 가열 사이클
```

**1단계의 결정적 차이 — EIS 측정 대역**

| | LIB | ASSB |
|---|---|---|
| 필요 대역 | 10 mHz ~ 10 kHz | **0.1 Hz ~ 7 MHz 이상** |
| 이유 | f_ct 근방 해상 | 이중층 단락 대역 + **인덕턴스 영역**까지 포착 필요 |
| 장비 | 일반 전기화학 워크스테이션 | **고주파 대응 임피던스 분석기** (일반 포텐쇼스탯 대역 초과) |
| 측정 밀도 | 디케이드당 10점 | 디케이드당 20점 권고 |

**이것이 ASSB 자가발열 도입의 첫 번째 실무 장벽이다.** 통상적인 배터리 평가 장비로는 MHz 대역 임피던스를 측정할 수 없으므로, **장비 확보가 프로젝트 0단계**가 된다.

## 10. 한계 및 향후 과제

### 10.1 기술적 미해결 과제

| # | 과제 | 심각도 |
|---|---|---|
| 1 | **ASSB 반복 가열의 기계적 열화 데이터 부재** — 열팽창 불일치에 의한 박리가 수백 사이클 누적 시 어떻게 되는지 공개 데이터 없음 | **최상** |
| 2 | **팩 레벨 UHFSH 실증 부재** — 50 K/min은 모델 외삽. 실측은 23.3 mAh 대칭셀의 0.5 K/min | **최상** |
| 3 | 전압 구동의 열적 안정성 — 7.3절의 정피드백 가능성 미검증 | 상 |
| 4 | ASSB 제약 조건의 실시간 관측 수단 부재 (CCD 초과·박리) | 상 |
| 5 | MHz 대역 차량용 전력변환의 EMI·비용·신뢰성 | 상 |
| 6 | 풀셀 발열 분포 — 복합 양극 내 국부 발열 집중 가능성 | 중 |

| 8 | ASSB 전용 안전 규격 미정립 | 중 |

### 10.2 조사 범위의 한계

- ASSB 자가발열의 공개 문헌이 **극히 적다.** 본 보고서 5.2절의 핵심 데이터는 사실상 단일 연구그룹(UC Berkeley / LBNL)의 1개 논문에 의존하며, **독립적인 재현 연구가 확인되지 않았다.** 단일 출처 의존은 본 보고서의 가장 큰 방법론적 약점이다.
- 기업 내부 데이터(삼성SDI, 도요타 등)는 비공개이며, 본 보고서의 산업 동향은 공개 발표·보도에 근거한다.
- 4.3절의 펄스-CCD 결과는 **가열이 아니라 충전 프로토콜 맥락**의 연구다. 가열 목적의 연속 인가 조건에 그대로 외삽되는지는 검증되지 않았다.
- 3.5절 설계 예제의 수치는 문헌 가정값 기반 차수 추정이다. 실제 설계는 실측 EIS로 재수행해야 한다.

### 10.3 향후 연구 방향

1. **화학 무관 제약 관측기** — LIB의 음극 전위 관측기에 대응하는 ASSB용 관측기(CCD 여유·계면 건전성 추정). 본 기술의 최대 병목.
2. **열-기계 연성 수명 모델** — dT/dt와 계면 박리를 연결하는 모델. 4.4절 리스크의 정량화.
3. **중간 주파수 영역 탐색** — LIB(kHz 이하)와 ASSB(MHz) 사이 대역에서 두 화학계에 모두 쓸 수 있는 절충 동작점이 존재하는지. 하이브리드 팩·플랫폼 공용화 관점에서 가치 있음.
4. **가열 겸용 진단** — 가열용 인가 신호를 임피던스 진단에 재활용하는 구성. 별도 EIS 하드웨어 없이 상태 추정이 가능해짐.

## 11. 결론 및 권고

### 11.1 결론

1. **자가 펄스 히팅은 LIB와 ASSB에 공통 적용 가능한 기술이며, 지배 방정식도 동일하다.** 그러나 최적 동작 주파수가 5~6 자릿수 떨어져 있고, 구동 방식(전류원 vs 전압원)과 제약 조건(리튬 석출 vs CCD·열응력)이 달라 **회로와 제어는 공용화되지 않는다.**
2. **ASSB에서 가열은 선택이 아니라 요건이다.** 특히 폴리머계는 60~80 °C 상시 운전이 필수이며, 산화물계도 상온 성능이 부족하다. 따라서 ASSB 개발에서 가열 기술은 **부가 기능이 아니라 기본 아키텍처**로 다뤄져야 한다.
3. **고주파는 ASSB에서 발열과 안전을 동시에 준다.** 이중층 단락으로 패러데이 전류가 줄고(계면 보호), 동시에 총 임피던스가 낮아져 발열이 커진다. 여기에 펄스가 CCD를 약 6배 확장한다는 독립적 결과가 더해져, 물리적 논거는 견고하다.
4. **그러나 실증 수준은 낮다.** 실험 검증은 23.3 mAh 대칭셀의 ΔT ≈ 1 °C/2 min이며, 인용되는 50 K/min은 팩 시뮬레이션 값이다. 반복 가열에 따른 기계적 열화 데이터는 존재하지 않는다.
5. **실무 장벽은 물리가 아니라 하드웨어다.** MHz 대역 전력변환은 기존 트랙션 인버터 재활용이 불가능하며, 전용 GaN 전력단·배선 레이아웃·EMI 대책이 팩 아키텍처 초기 단계에서 요구된다.

## 부록 A. 주요 수식 정리

**A.1 발열량 — 전류 구동 (LIB 관례)**
```
Q_gen = Σ_n  I_n,rms² · Re{ Z(n·f₀, T, SOC) }
```

**A.2 발열량 — 전압 구동 (ASSB / UHFSH 관례)**
```
Q_gen = V_cell,rms² · Re{Z(f,T)} / |Z(f,T)|²
```

**A.3 Bernardi 발열식 (일반형)**
```
Q_gen = I·(V − U_ocv) − I·T·(dU_ocv/dT)
        └ 비가역(분극) ┘  └ 가역(엔트로피) ┘
```
양방향 펄스에서 가역열 항은 한 주기 평균이 상쇄되고, 비가역열만 누적된다.

**A.4 집중 열모델**
```
m·c_p·dT/dt = Q_gen(T) − h·A·(T − T_amb)
```

**A.5 단열 승온율**
```
dT/dt |_adiabatic = Q_gen(T) / (m·c_p)
```

**A.6 고체전해질 면적비저항**
```
ASR_SE = L / σ          [Ω·m²]
```

**A.7 면적 발열 밀도 (고주파 극한, |Z| → R_SE)**
```
q″ = V_rms² / ASR_SE     [W/m²]
```

**A.8 총 전류의 분해 (계면)**
```
i_total = i_rxn + i_inf
i_inf / i_total  →  1   as  f → ∞     (이중층 단락)
```

**A.9 승온 에너지 비율**
```
E_th / E_cell = (ρ·c_p·ΔT) / E_vol
```
`E_vol` = 체적 에너지밀도 [J/m³]. 순수 열에너지 기준이며, 전력변환 효율·보온 전력 미포함.
